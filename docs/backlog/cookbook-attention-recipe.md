# Attention page as a cookbook recipe

The leader-i attention page, a full HTML page overlay, is captured as an extra screenshot but does not ship in
`cookbook/`, so a reader cannot install what the shot shows. It runs today only from the maintainer's
own setup (`~/.config/agterm/scripts/attention.py` with its `attention.html` template).

- Port the GitHub path only. Drop the work-GitLab branch and the `ump-dev.rc` source; keep codex as the
  judge and leave jev optional.
- Follow `cookbook/CONTRIBUTING.md` and pin the minimum agterm version it needs.
